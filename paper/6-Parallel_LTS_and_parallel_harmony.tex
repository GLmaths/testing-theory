\section{Parallel LTS and parallel harmony}\label{sec:par}

This section is a complement to the Harmony lemma, which does not depend on
it. A composition of LTSs can be composed again (\cref{def:par}): we show
that the composition of a memory with a parallel composition
$P \parallel Q$ of the syntax is the composition of the system
$\rho \lpar P$ with the program $Q$.

The system $\rho \lpar P$ is composed with the program
$Q$, which interacts with the memory of the system (through $\syncM$) and
with the channels of $P$: let $\syncC$ relate the dual actions on a channel,
$c!v \syncC c?v$ and $c?v \syncC c!v$, and let
${\syncS} \subseteq (A_{\M} \uplus A_{\mathsf{prog}}) \times A_{\mathsf{prog}}$
be the least relation such that
\[
\mu_{\M} \syncS \mu \ \text{ if } \mu_{\M} \syncM \mu
\qquad\qquad
\mu_1 \syncS \mu_2 \ \text{ if } \mu_1 \syncC \mu_2 .
\]

Together with \cref{lem:harmony}, the next lemma describes the reductions
of $\conf{\rho}{P \parallel Q}$ by the silent transitions of the composition
$(\rho \lpar P) \lpar Q$.

\begin{lemma}[Parallel harmony]\label{lem:par-harmony}
For all $\rho, P, Q, s, \rho', R$,
\[
\begin{array}{l}
\rho \lpar (P \parallel Q) \step{\tau}{s} \rho' \lpar R\\[2pt]
\quad\iff\
R = P' \parallel Q' \text{ and }
(\rho \lpar P) \lpar Q \step{\tau}{s} (\rho' \lpar P') \lpar Q'
\text{ for some } P', Q',
\end{array}
\]
where the outer composition is for $\syncS$ and the inner one for $\syncM$.
\end{lemma}

\begin{proof}
($\Rightarrow$) By case analysis on the last rule of the transition of the
program $P \parallel Q$ from which the transition of
$\rho \lpar (P \parallel Q)$ is derived, by the rule Right or Sync. ParL is
the rule Left, with the same rule for $\rho \lpar P$. ParR is either the rule Right, for a silent move of
$Q$, or the rule Sync between a move of the memory (rule Left inside
$\rho \lpar P$) and a request of $Q$, with choice $\epsilon \cdot t = t$.
ComL and ComR are the rule Sync between a channel action of $P$ (rule
Right inside $\rho \lpar P$, which does not change $\rho$) and the dual action
of $Q$, with choice $t \cdot t' = \{t,t'\}$.

($\Leftarrow$) By case analysis on the last rule of the transition of
$(\rho \lpar P) \lpar Q$, the same correspondence in the other direction;
the channel actions of programs always carry a single tag, so that the choice
of a communication between $P$ and $Q$ is a pair $\{t,t'\}$.
\qed
\end{proof}

\begin{remark}\label{rem:prog-level}
The mechanisation also defines an LTS directly on the pairs
$\conf{\rho}{P}$, by induction on the program and without the actions of the
memory: a gate, an initialisation and a measurement are silent transitions
that update the memory. Its silent transitions are those of the composition
$\rho \lpar P$ (\texttt{pre\_harmony}); the Harmony lemma is first proved for
this LTS (\texttt{harmony}), and \cref{lem:harmony} follows
(\texttt{harmony\_composition}).
\end{remark}
